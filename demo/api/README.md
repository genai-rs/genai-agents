# Rust API server for genai-agents-demo-api

The HTTP API of the demo's web pages: a chat with the household assistant, with approvals for the calls that need them, and a voice page that talks to GPT-Live while the assistant does the work it delegates. The server is generated from this file by openapi-generator-timvw-rust (`targets: [server]`); see `demo/scripts/generate-api.sh`.

## Installation

Put the package under your project folder in a directory named `genai-agents-demo-api` and add the following to `Cargo.toml` under `[dependencies]`:

```toml
genai-agents-demo-api = { path = "./genai-agents-demo-api" }
```
